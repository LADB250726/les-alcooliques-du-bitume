# Les Alcooliques du Bitume — VTC ETS2

## Modifier facilement le site

### 1. Informations principales
Dans `index.html`, tout en haut se trouve la **ZONE FACILE À MODIFIER**.

### 2. Présentation
Cherche `MODIFIER ICI LA PRÉSENTATION DE LA VTC`.

### 3. Équipe
Cherche `ÉQUIPE — MODIFIER LES NOMS ICI`.
Les Fondateurs et Modérateurs sont regroupés dans cette partie.

### 4. Convois
Cherche `CONVOIS — MODIFIER LES INFOS ICI`.
Change la date, le titre, le trajet, l'heure et la distance.

### 5. Photos
Mets tes photos dans le dossier `assets`.
Exemples :
- convoi-01.png
- convoi-02.png
- convoi-03.png
- convoi-04.png

Puis utilise ces noms dans la section `GALERIE` de `index.html`.

### 6. Publication
Après chaque modification sur GitHub :
1. Enregistre le fichier.
2. Clique sur `Commit changes`.
3. GitHub Pages republie automatiquement le site après un court délai.
